    Remarks

    This class models the elements required to build a cc65 project: input and header files, target platform, optimisation flag and the output filename. Instances are JSON-serializable via AsJson and can be restored with FromJson(String).

    The class is lightweight and intended to be used as a data transfer object between the UI and the build/runner components of the application.
