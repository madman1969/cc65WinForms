    Remarks

    This service is responsible for: - Validating the provided CC65Project prior to compilation. - Building command-line arguments using the configured IArgumentBuilderTOptions. - Executing the compiler through ICommandExecutor. - Parsing compiler output via IErrorParser. - Reporting progress through both an IProgressT and the ProgressChanged event. The service uses dependency injection for all external concerns (execution, argument building, error parsing and logging) to keep the class testable and focused on orchestration.
