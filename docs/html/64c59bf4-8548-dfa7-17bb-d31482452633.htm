    Remarks

    This record is immutable once constructed (uses C# init-only properties with required). - Success indicates whether the overall launch and run completed without detected failure. - ExitCode is the numeric exit code produced by the emulator process (conventionally 0 for success). - Errors contains any diagnostic or wrapper-level error messages captured while preparing or launching the emulator. - StandardOutput and StandardError contain the complete captured stdout/stderr streams from the emulator process. Callers should inspect Success first; if false, examine Errors, StandardError, and ExitCode to determine the cause and appropriate remediation.

    Example

    var result = new EmulatorLaunchResult { Success = true, ExitCode = 0, Errors = Array.Empty<string>(), StandardOutput = "Emulator started...", StandardError = string.Empty };
