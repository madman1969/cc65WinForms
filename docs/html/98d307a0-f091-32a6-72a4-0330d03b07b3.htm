    Remarks

    - Replaces any previously configured factory; subsequent calls will overwrite the existing factory. - If this method is not called, the library falls back to Instance and Instance when creating loggers. - This method does not perform synchronization; callers should ensure it is invoked in a thread-safe manner (typically once during initialization).
