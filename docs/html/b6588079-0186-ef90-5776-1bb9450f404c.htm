    Builds the command-line arguments represented as an ordered sequence of tokens. Implementations should return each argument or flag as a separate string element.

    options  TOptions
    The options instance containing values to convert into arguments. May be null if the implementation supports defaults.

    Return Value

    IEnumerableString
    An IEnumerableT containing the argument tokens in the order they should be passed to the executable. The returned sequence must not include the executable name itself; it should contain only the arguments.

    Remarks

    - The sequence should preserve ordering for options where order matters. - Implementations must ensure tokens are already escaped or quoted as required by the target process invocation method, or clearly document that callers are responsible for quoting/escaping. - Prefer returning an empty sequence rather than null when there are no arguments.
