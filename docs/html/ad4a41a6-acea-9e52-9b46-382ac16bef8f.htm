    cc65Wrapper.Models Namespace

    Immutable result and progress-event types returned by the compiler and emulator launcher services.

    Classes

    BuildProgressEventArgs Event arguments for build progress updates
    CommandResult Represents the result of executing a command or external process.
    CompilationResult Represents the result of a single compiler invocation.
    EmulatorLaunchResult Result returned by the wrapper after attempting to launch an emulator process.

    Enumerations

    BuildPhase Represents the logical phases of a build operation reported via BuildProgressEventArgs. Handlers receiving progress updates can use these values to determine which part of the pipeline the message relates to (initialization, validation, argument construction, compilation, parsing, or completion).
