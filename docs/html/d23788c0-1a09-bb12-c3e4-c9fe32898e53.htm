    cc65Wrapper.Parsers Namespace

    A chain-of-responsibility set of parsers that convert raw cc65 compiler error output into structured

    Classes

    DefaultErrorParser Default fallback parser for error lines that don't match other patterns. This parser is used when no higher-priority parser recognizes the input. It attempts a best-effort parse using colon-separated segments: filename:type:message. If the line does not contain colons it will treat the whole line as an error message.
    ErrorParser Main error parser that delegates individual error lines to a set of IErrorLineParser implementations. The parser: - Orders provided line parsers by their Priority (descending) so higher priority parsers are attempted first. - Splits the raw error output into distinct non-empty lines and attempts to parse each line using the first parser whose CanParse(String) returns true. - Collects and returns the resulting Cc65Error instances. - Emits structured log entries for start, per-line success/failure, and completion.
    FivePartErrorParser Parses error lines with 5 parts (filename:line:type:error:extra)
    FourPartErrorParser Parses error lines with 4 parts (filename:line:type:error)
    ThreePartErrorParser Parses error lines with 3 parts (filename:type:error)

    Interfaces

    IErrorLineParser Parses a single line of cc65 tool output and converts it into a Cc65Error.
