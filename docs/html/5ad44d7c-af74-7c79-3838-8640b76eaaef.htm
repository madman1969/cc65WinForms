    Remarks

    Creating an instance of WorkingDirectoryContext stores the current working directory (via the provided IFileSystem) and then changes the working directory to the supplied workingDirectory. Calling Dispose restores the original working directory.

    This type is intended to be used with a using statement to guarantee restoration:

    C#
    using (new WorkingDirectoryContext(path, fileSystem))
{
    // operations that require the working directory to be 'path'
}
// original working directory is restored here

    The class relies on the IFileSystem abstraction to allow easier testing and to avoid direct dependencies on Directory operations.
