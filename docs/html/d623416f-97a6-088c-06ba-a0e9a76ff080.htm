    Usage Note

    In Visual Basic and C#, you can call this method as an instance method on any object of type IServiceCollection. When you use instance method syntax to call this method, omit the first parameter. For more information, see Extension Methods (Visual Basic) or Extension Methods (C# Programming Guide).

    Remarks

    Registered services: - Core abstractions: ICommandExecutor, IFileSystem. - Argument builders for domain models (e.g. CC65Project, EmulatorLaunchOptions). - Error line parsers (registered in priority order) and a composite IErrorParser. - Main services: ICompiler, IEmulatorLauncher and IProjectService. Note on error parsers: multiple implementations of IErrorLineParser are registered. They are expected to be consumed in the registered order so that more specific parsers can be attempted before falling back to the DefaultErrorParser.
