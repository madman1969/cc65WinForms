    Cc65Emulators Class

    Holds emulator executable paths for supported platforms and provides legacy helpers to launch a compiled binary in the selected emulator.

    Remarks

    This class exists primarily for backward compatibility with older code. Newer code should use an implementation of IEmulatorLauncher and resolve it via dependency injection.
