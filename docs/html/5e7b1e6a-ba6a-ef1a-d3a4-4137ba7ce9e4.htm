    Parameters

    project  CC65Project
    The project to compile. This parameter must not be null.
    progress  IProgressBuildProgressEventArgs  (Optional)
    Optional IProgressT reporter that receives BuildProgressEventArgs as the build proceeds. If null, progress will still be published via the ProgressChanged event when supported by the implementation.
    cancellationToken  CancellationToken  (Optional)
    A CancellationToken used to cancel the compilation operation. Implementations should observe this token and attempt to stop work promptly when cancellation is requested.

    Return Value

    TaskCompilationResult
    A task that completes with a CompilationResult describing the outcome (success, errors, warnings, and produced artifacts). The task completes successfully when compilation finishes (even if there are build errors); it completes as OperationCanceledException if the operation is canceled.

    Remarks

    Implementations should: - Validate the provided project and throw ArgumentNullException for a null reference. - Honor cancellationToken and cease work when cancellation is requested. - Report incremental progress via both the optional progress reporter and the ProgressChanged event (if supported). - Not block the calling thread; all long-running work must be performed asynchronously.

    Exceptions

    ArgumentNullExceptionThrown if project is null.
    OperationCanceledExceptionThrown if the operation was canceled via cancellationToken.
