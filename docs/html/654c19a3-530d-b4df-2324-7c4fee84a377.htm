    Remarks

    Each enum member corresponds to a cc65/ca65 target name and is intended to be used when selecting the target platform for compilation and linking. Use the enum value's name (e.g. CC65ProjectTypes.c64) or call ToString().ToLowerInvariant() to obtain the usual cc65 target string (for example, "c64") when passing arguments to the toolchain.
