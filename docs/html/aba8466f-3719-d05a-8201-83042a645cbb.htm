    cc65Wrapper.Abstractions Namespace

    Interfaces defining the compiler, emulator launcher, project persistence, command execution, argument building and error parsing abstractions used throughout the library for dependency injection and testability.

    Interfaces

    IArgumentBuilderTOptions Provides an abstraction for translating an options object into a sequence of command-line argument tokens for invoking external tools (for example, cc65).
    ICommandExecutor Provides an abstraction for running external processes/commands. Implementations are responsible for starting the process, capturing output, and producing a CommandResult describing the outcome.
    ICompiler Defines an abstraction for compiling CC65 projects and reporting build progress. Implementations perform the actual invocation of the CC65 toolchain and produce a CompilationResult describing success, diagnostics and outputs.
    IEmulatorLauncher Defines an abstraction for launching emulators for a CC65 project. Implementations are responsible for starting the configured emulator process, wiring up any required arguments or working directories from the provided CC65Project and Cc65Emulators configuration, and returning an EmulatorLaunchResult describing the outcome.
    IErrorParser Parses raw compiler output from the cc65 toolchain and produces structured error objects.
    IFileSystem Provides an abstraction over basic file system operations used by the application.
    IProjectService Defines an abstraction for loading and saving CC65Project instances to and from disk as JSON.
