    ICompiler Interface

    Defines an abstraction for compiling CC65 projects and reporting build progress. Implementations perform the actual invocation of the CC65 toolchain and produce a CompilationResult describing success, diagnostics and outputs.

    Events

    ProgressChanged Raised when compilation progress changes. Subscribers receive BuildProgressEventArgs updates describing the current step, percentage complete and any textual status. Implementations may raise this event from a background thread; consumers receiving UI updates should marshal to the UI thread if required.
