    IArgumentBuilderTOptions Interface

    Provides an abstraction for translating an options object into a sequence of command-line argument tokens for invoking external tools (for example, cc65).

    Type Parameters

    TOptions
    The type that describes the options or settings used to produce the arguments. This interface is contravariant in TOptions (see the in modifier), allowing implementations to accept base option types.

    Methods

    Build Builds the command-line arguments represented as an ordered sequence of tokens. Implementations should return each argument or flag as a separate string element.
