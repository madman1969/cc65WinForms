    Remarks

    - Validates inputs before attempting to resolve the emulator path. - Uses GetEmulatorPath to choose the appropriate emulator executable based on the project's target platform. - Builds arguments via the injected IArgumentBuilderTOptions. - Executes the emulator via the injected ICommandExecutor and logs progress. - Any exceptions are caught and converted into an EmulatorLaunchResult with Success=false.

    Exceptions

    ArgumentNullExceptionIf project or emulators is null (validation is performed internally).
    ArgumentExceptionIf WorkingDirectory is null or empty.
    DirectoryNotFoundExceptionIf WorkingDirectory does not exist.
