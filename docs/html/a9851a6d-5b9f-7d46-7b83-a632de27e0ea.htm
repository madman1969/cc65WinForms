    ErrorParser Class

    Main error parser that delegates individual error lines to a set of IErrorLineParser implementations. The parser: - Orders provided line parsers by their Priority (descending) so higher priority parsers are attempted first. - Splits the raw error output into distinct non-empty lines and attempts to parse each line using the first parser whose CanParse(String) returns true. - Collects and returns the resulting Cc65Error instances. - Emits structured log entries for start, per-line success/failure, and completion.
