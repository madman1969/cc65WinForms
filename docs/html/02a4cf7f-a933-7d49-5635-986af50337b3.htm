    Parameters

    errorOutput  String
    The raw compiler output to parse (for example, stderr or combined stdout/stderr). May be null or an empty string; implementations should handle this and return an empty list.

    Return Value

    ListCc65Error
    A list of parsed Cc65Error instances. The list will be empty when no parseable messages are found or when errorOutput is null/empty.

    Remarks

    Parsers should preserve the original message text in the resulting Cc65Error and populate location and severity fields when information is available in the input.
