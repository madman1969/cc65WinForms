    IEmulatorLauncher Interface

    Defines an abstraction for launching emulators for a CC65 project. Implementations are responsible for starting the configured emulator process, wiring up any required arguments or working directories from the provided CC65Project and Cc65Emulators configuration, and returning an EmulatorLaunchResult describing the outcome.
