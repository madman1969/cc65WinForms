    Parameters

    executable  String
    The path or name of the executable to run. This should not include command-line arguments.
    arguments  IEnumerableString
    A sequence of command-line arguments to pass to the executable. Each entry represents a single argument; implementations should handle any necessary quoting/escaping when constructing the process start info.
    environmentVariables  IDictionaryString, String  (Optional)
    Optional collection of environment variables to set for the process. If null, the process should inherit the parent process's environment. Keys are variable names and values are variable values.
    workingDirectory  String  (Optional)
    Optional working directory for the launched process. If null, the current working directory of the host process should be used.
    cancellationToken  CancellationToken  (Optional)
    Token to observe for cancellation. Implementations should respect this token and attempt to terminate the launched process promptly if cancellation is requested. Cancellation may result in an OperationCanceledException being thrown or a canceled task result, depending on the implementation.

    Return Value

    TaskCommandResult
    A task that completes with a CommandResult containing the process exit code, captured standard output and standard error, and any additional execution metadata. See CommandResult for details.
