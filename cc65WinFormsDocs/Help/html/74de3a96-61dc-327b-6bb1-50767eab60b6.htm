    cc65WinForms Namespace

    [Missing <summary> documentation for "N:cc65WinForms"]

    Classes

    InvisibleCharsRenderer Renders visible markers for normally invisible characters inside a FastColoredTextBox text range. Currently draws: - a small dot for space characters, - a pilcrow "¶" at end-of-line positions.
    MainForm Main application window for the cc65WinForms project. Provides the primary UI surface including: - Project tree view population and management - Editor tab creation and management (based on FastColoredTextBox) - Navigation through edit history (forward/back) - UI helpers such as cursor position updates and line highlighting toggles
    ProjectSettings A dialog that displays and edits settings for a CC65Project. Responsibilities: - Bind current project values to UI controls when the dialog loads. - Allow the user to change project name, working directory, target platform, output file and basic build options. - Validate and apply changes back to the CC65Project instance, marking the project as modified when values change.
    TbInfo Holds auxiliary information related to a text box editor instance. Currently this class exposes the AutocompleteMenu used to show completion suggestions for a given text box.
