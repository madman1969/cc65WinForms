    Return Value

    Cc65Error
    A Cc65Error instance populated from the parsed components. If the line contains at least one colon the method interprets the first segment as the filename, the second as the type, and the remainder (joined by ':') as the message. If no colon is present the entire line is returned as the error message with an empty filename and Type set to "Error". The returned LineNumber is always 0 since this parser does not extract line numbers.
