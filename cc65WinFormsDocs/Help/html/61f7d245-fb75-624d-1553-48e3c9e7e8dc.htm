    Parameters

    executable  String
    The executable name or full path to run (for example, "cc65").
    arguments  IEnumerableString
    Sequence of arguments to pass to the executable. The sequence will be joined for logging, but passed to CliWrap as an enumerable.
    environmentVariables  IDictionaryString, String  (Optional)
    Optional environment variables to set for the process. If provided, the dictionary is copied to a read-only mapping and passed to the process environment.
    workingDirectory  String  (Optional)
    Optional working directory for the process. If null, the current process working directory is used.
    cancellationToken  CancellationToken  (Optional)
    Token used to cancel the execution. If cancellation is requested, the underlying CliWrap execution will be cancelled and an OperationCanceledException may be thrown by the task.

    Return Value

    TaskCommandResult
    A CommandResult containing the process ExitCode, captured StandardOutput, and StandardError.

    Implements

    ICommandExecutorExecuteAsync(String, IEnumerableString, IDictionaryString, String, String, CancellationToken)

    Remarks

    - The method configures CliWrap with CommandResultValidation.None so non-zero exit codes are returned rather than thrown. - Standard output and error are captured via ExecuteBufferedAsync. - Lifecycle events (executing, completed, failed) are logged through the injected logger.
