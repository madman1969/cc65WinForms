    Remarks

    This class wraps calls to the application's root IServiceProvider (via Program.ServiceProvider) to make resolving common services convenient from places where constructor injection is not available (for example legacy WinForms event handlers). Prefer constructor injection where possible. Important: - [!:GetRequiredService<T>] is used under the hood; if a service is not registered an InvalidOperationException will be thrown. - Do not use these helpers to resolve scoped services from the root provider; resolving scoped services from the root provider can lead to incorrect lifetimes. Create an appropriate scope when you need scoped services.
