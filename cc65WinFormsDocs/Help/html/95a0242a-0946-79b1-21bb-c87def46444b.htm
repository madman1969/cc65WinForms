    Remarks

    This class centralizes registration of core abstractions, argument builders, error parsing implementations and the primary services (ICompiler and IEmulatorLauncher). All registrations use singleton lifetime because the wrapped operations are stateless and shared instances simplify lifetime management in typical desktop and CLI applications.

    Methods

    AddCc65Wrapper(IServiceCollection) Adds all cc65Wrapper services to the provided IServiceCollection.
    AddCc65Wrapper(IServiceCollection, ActionILoggingBuilder) Adds cc65Wrapper services and configures logging using the provided delegate.
