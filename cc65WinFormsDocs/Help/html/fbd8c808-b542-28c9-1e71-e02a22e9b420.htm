    Remarks

    Each member is defined as a bitmask so multiple file types can be combined using bitwise operations (for example CC65FileTypes.SourceFile | CC65FileTypes.IncludeFile). Typical usages:
    • SourceFile for source code files (C, assembly, etc.)
    • IncludeFile for header/include files
    • None indicates no file type selected

    Example

    Example: check whether a combined value includes SourceFile:
    C#
    var combined = CC65FileTypes.SourceFile | CC65FileTypes.IncludeFile;
bool hasSource = (combined & CC65FileTypes.SourceFile) != 0; // For single-bit flags, '!= 0' is sufficient.
// For multi-bit combinations, use: (combined & flag) == flag
// Alternatively, you can use: combined.HasFlag(CC65FileTypes.SourceFile) (slower, but more readable)

    Members

    None0 No file type specified. This is the default value (0) and indicates that no file-type flags are set.
    SourceFile2 Represents a source file (for example: C or assembly source understood by cc65). This value is a bit flag and can be combined with other file-type flags.
    IncludeFile4 Represents an include/header file (for example: C headers). This value is a bit flag and can be combined with other file-type flags.
