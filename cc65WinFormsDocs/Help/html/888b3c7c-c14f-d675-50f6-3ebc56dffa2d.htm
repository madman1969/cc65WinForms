    errorOutput  String
    Raw multi-line error output from the cc65 toolchain. May contain CR, LF or CRLF line endings.

    Return Value

    ListCc65Error
    A list of parsed Cc65Error objects. Returns an empty list if errorOutput is null, empty or whitespace-only. Duplicate lines in the input are ignored (each distinct non-empty line is parsed once).

    Implements

    IErrorParserParse(String)

    Remarks

    Processing steps: 1. If errorOutput is null/whitespace, an empty list is returned. 2. The input is split on environment newlines, CR and LF. Empty entries are removed and distinct lines are retained. 3. For each distinct line, the parser selects the first IErrorLineParser whose CanParse returns true and calls its Parse method. 4. Parsing exceptions for individual lines are caught and logged as warnings; parsing continues. 5. The method logs the number of errors and warnings parsed on completion.
