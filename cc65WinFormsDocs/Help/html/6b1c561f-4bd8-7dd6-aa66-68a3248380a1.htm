    IErrorLineParser Interface

    Parses a single line of cc65 tool output and converts it into a Cc65Error.

    Remarks

    Implementations should recognize specific error/warning line formats produced by the cc65 toolchain. Typical usage is to call CanParse(String) to determine applicability before calling Parse(String). Parsers are expected to be lightweight, stateless, and reentrant so they can be reused across files and threads.

    Example

    Example: choose the first parser (highest priority first) that can parse a given line.
    C#
    // Parsers with higher Priority values are evaluated first.
var parsers = new[] { parserA /* Priority=100 */, parserB /* Priority=50 */ };
foreach (var line in lines)
{
    var parser = parsers.OrderByDescending(p => p.Priority).FirstOrDefault(p => p.CanParse(line));
    if (parser != null)
    {
        var err = parser.Parse(line);
        // handle err
    }
}

    Properties

    Priority Priority used when multiple parsers are available; higher values are checked before lower values.

    Methods

    CanParse Determines whether this parser can handle the specified cc65 output line.
    Parse Parses the specified cc65 output line and returns a corresponding Cc65Error.
