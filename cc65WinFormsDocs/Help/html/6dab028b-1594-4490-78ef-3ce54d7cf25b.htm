    TaskBufferedCommandResult
    A BufferedCommandResult containing the exit code, standard output and error streams from the emulator process started by this method.

    Remarks

    - This is a legacy, static helper retained for backward compatibility. - For new code prefer using an IEmulatorLauncher implementation. - The method temporarily changes the process current directory to the project's working directory and restores it before returning.

    Exceptions

    ArgumentNullExceptionThrown when project or emulators is null.
    ArgumentExceptionThrown when project.WorkingDirectory is null, empty or whitespace.
    DirectoryNotFoundExceptionThrown when the project's working directory does not exist.
